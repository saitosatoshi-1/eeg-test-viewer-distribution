研究説明・電磁的同意

脳波判読に関する研究の説明

本研究は、脳波判読経験のある医師を対象に、脳波の判読行動と発作間欠期てんかん性放電（IED）の判定結果との関連を探索的に調べ、将来の脳波判読教育や判読支援に役立つ基礎資料を得ることを目的とします。個々の医師の成績評価には使用しません。

参加方法と研究期間

Temple University Hospital EEG Corpusの既存の匿名化脳波を用い、Web viewerで20問の判読課題に回答していただきます。あわせて、診療科、資格、診療経験年数、脳波判読件数、ビデオ脳波判読歴等の背景情報と事後アンケートを取得します。患者の診療情報は新たに取得せず、実際の患者診療には影響しません。

研究期間は研究実施許可受領後から2030年11月1日まで、研究対象者登録締切日は2027年11月1日です。参加者募集と判読データ収集は原則として倫理審査承認後1年以内に完了する計画です。

負担・リスクと利益

判読課題と背景情報・事後アンケートへの回答に時間を要します。侵襲はありませんが、判読結果に関する心理的負担や個人情報漏えいのリスクがあります。個人が特定される形で結果は公表せず、情報へのアクセスを制限します。参加による直接の利益はありません。

参加は任意です

参加するかどうかはご自身の自由意思で決められます。参加しない場合や途中で中止した場合にも不利益はありません。テスト終了後の事後説明を受けてから、研究への同意を撤回し、取得したデータの利用を拒否することもできます。判読は普段どおりに行ってください。

同意撤回・データ利用拒否は、下記の問い合わせ窓口へ氏名、所属、メールアドレスを添えてメール等でお申し出ください。該当データを特定し、利用停止・削除等の対応を行います。

個人情報の管理と保管・廃棄

氏名・所属施設・メールアドレスを取得し、研究用IDとの対応表を作成します。対応表は斉藤聡志が作成し、谷口豪が管理します。暗号化したUSBメモリに保存し、NCNP病院てんかん診療部医長室の施錠キャビネットで保管します。アクセスできるのは谷口豪と斉藤聡志に限り、研究解析用データと分離して管理します。

氏名・所属施設・メールアドレスと対応表は、同意撤回・利用拒否に対応するため研究終了時まで保管し、研究終了後に復元困難な方法で消去します。研究解析用データは、研究終了日から5年または研究結果最終公表日から3年のいずれか遅い日まで、アクセスを制限した保存媒体・保存領域に保管し、期間終了後に復元困難な方法で消去します。結果は個人を特定できない形で学会・論文等で公表することがあります。

米国Temple Universityへの情報提供

TUH EEG Corpusの利用者登録・管理のため、全参加医師の判読データ収集終了後に、氏名・所属施設・メールアドレスのみを米国Temple Universityのデータ管理担当者へ暗号化通信を用いて一括提供する予定です。判読結果や操作ログは同大学へ提供しません。

同大学では利用者登録記録を保持する必要があります。一方、NCNPから提供する参加医師名簿について同大学が別途管理責任を引き受けることはできないとの回答を受けています。具体的な保存システム、保存期間、削除方法、安全管理措置の詳細は現時点で確認できていません。この点を理解したうえで参加をご判断ください。

Web viewerと研究データの取扱い

Web viewerは米国オレゴン州のRender社Web Serviceで運用し、斉藤聡志が設定・運用を管理します。共通パスワードで認証し、公開サイトの通信はHTTPSで暗号化します。IPアドレスを研究データとして取得・保存する設計にはしていません。

現在のviewerでは研究データがサーバーへ送信・保存されます。テスト終了後は結果JSONを端末にダウンロードして、斉藤聡志（satoshi.saito@ncnp.go.jp）へメールで提出してください。データ利用を拒否する場合はメール提出を行わず、問い合わせ窓口へ利用停止・削除をお申し出ください。

取得した情報と研究の主要仮説

本テストでは、判読結果に加え、モンタージュの切替回数・各モンタージュの表示時間、感度・時定数等の設定変更、総判読時間などの操作ログを記録しました。これらは研究目的に限定して利用し、個々の医師の能力・成績や人事の評価には使用しません。

本研究の主要仮説は「複数のモンタージュを確認する行動がIED判定エラーの減少と関連する」というものです。具体的には、1エポック内で双極誘導と参照基準導出の両方をそれぞれ1秒以上表示した行動と、IEDの正判定・誤判定との関連を探索的に検討します。因果関係を直接検証する研究ではありません。

事前に詳しく説明しなかった理由

操作ログの具体的な取得項目や主要仮説を先に知ることで、モンタージュ切替を意識するなど、通常と異なる判読行動が生じる可能性（ホーソン効果）があります。この影響を避けるため、IC手続の一部簡略化として、これらの具体的内容の事前説明を省略する計画としています。

説明を受けた後の選択
